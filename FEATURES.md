# Функции TeleOSINT

## Модуль: Telegram

### Анализ пользователей
- Получение профиля по @username, ID, номеру телефона
- История смены имён и аватаров (при наличии доступа)
- Общие группы с целевым аккаунтом
- Время последней активности (если не скрыто)

### Анализ каналов и групп
- Количество подписчиков и динамика роста
- Список администраторов и их роли
- Топ активных участников
- Частота и тематика публикаций
- Связанные каналы и боты

### Граф связей
- Построение графа связей 1-го и 2-го порядка
- Экспорт в формат GEXF (Gephi) и GraphML
- Визуализация через встроенный рендер (networkx + matplotlib)

### Экспорт и мониторинг
- Экспорт сообщений: JSON, CSV, XLSX
- Скачивание медиафайлов с метаданными
- Мониторинг каналов в реальном времени по ключевым словам
- Уведомления через Telegram-бот или webhook

## Модуль: Другие платформы

- **VK**: поиск по ID, анализ друзей, групп, публикаций
- **GitHub**: поиск по email, анализ активности разработчика
- **Instagram**: базовый анализ публичных профилей
- **Twitter/X**: поиск твитов, анализ подписок

## Безопасность и анонимность

- Поддержка Tor (SOCKS5 через порт 9050)
- Ротация прокси из списка
- Задержки между запросами для обхода rate-limit
- Режим "тихой работы" без записи логов
